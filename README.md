# ⭐ Les Étoiles de Taounate

Application PWA mobile-first de gestion d'une école de football, conçue pour fonctionner hors ligne.

## Fonctionnalités
- Joueurs et recherche
- Catégories
- Présences
- Évaluations
- Cotisations
- Matchs
- Packs
- Sauvegarde/restauration JSON
- IndexedDB
- Service Worker
- PWA installable
- Préparée pour GitHub Pages et PWABuilder

## GitHub Pages
Publier le contenu de ce dossier dans un dépôt GitHub puis activer Pages sur la branche principale et le dossier `/root`.

## PWABuilder
Une fois GitHub Pages actif, ouvrir PWABuilder et analyser l'URL publique du site. Corriger les éventuels avertissements avant de générer le package Android.

## Important
L'APK est généré à partir de la PWA publiée ; ce dépôt contient la version web installable et hors ligne.
